# Pankaj Yadav — Portfolio

A modern, interactive personal portfolio website built to showcase my projects, technical skills, and journey as a Computer Science & Engineering student.

## Live Website

https://portfolio-jims.vercel.app/

## About

I'm Pankaj Yadav, a Computer Science & Engineering student at IIIT Una interested in software development, problem solving, and building interactive digital experiences.

This portfolio is designed around a minimal, dark, experimental aesthetic with interactive elements and motion rather than a traditional static portfolio layout.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Pankajxrao/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
